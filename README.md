# Genome Foundation Model 진화 지도

**[Live Demo](https://pwy02221-dev.github.io/genome-foundation-model-landscape/)**

58편의 문헌에서 추출한 30개 게놈 Foundation Model의 진화를 인터랙티브하게 시각화한 단일 페이지 웹 애플리케이션.

아키텍처 계보(Transformer→SSM→Hybrid), 토큰화 전략, 적용 범위 확장, 예측→설계 스펙트럼, 패러다임 수렴을 다룸.

Built with Plotly.js. Data sourced from the LLM Wiki project.
